# enclavelogistics.com

The static website for Enclave Logistics Limited, served by GitHub Pages at https://enclavelogistics.com.

- It is plain HTML, CSS and JS with no build step on GitHub. All asset paths are root-relative (`/styles.css`, `/images/...`).
- The pages are generated by a small Python script (`src/build.py`). It is kept outside this repo, so it is never published. To change the copy, edit and run that script, then copy its output here.
- The quote form posts to Formspree and redirects to `/thank-you.html`.
- The pre-redesign site is tagged `pre-redesign-2026-10-11`.
